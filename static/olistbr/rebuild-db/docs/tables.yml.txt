type: fact or dim

structure:
<> indicate customisable fields

<type>, table type = dim, fact
<dtype>, any valid sqlserver data type = CHAR(5), DECIMAL(9, 4), etc.
<nullable>, able to have null = true, false
<sk>, option to be sk, must have dtype INT, IDENTITY(<seed>, <increment>)
<seed>, value of first row added = 1, 2, ...
<increment>, how much to increment for each new row = 1

<pk_name>, has format: pk_<table1>
<pk_cols>, must be any existing col in table

schemas, tables, and columns must be ordered => as a list

<fk> add fk on existing col
<fk_name>, has format: fk_<child>_<parent>__<col>

<db_name>

    - <table1_name>:
        filename: file1.csv

        columns:
            - <column1>:
                dtype:
                nullable:
                sk:
                    seed:
                    increment:
            - <column2>
                dtype:
                ...
        constraints:
            <pk_constraint>
                type: PRIMARY KEY
                columns:
                    - <column1>
            <fk_constraint>
                type: FOREIGN KEY
                column: <column2>
                references:
                    <table0>:
                        schema: <schema1_name>
                        column: <schema1_column_name>

            <uq_constraint>

                    - <column_a>

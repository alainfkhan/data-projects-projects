====================================================================================================
definitions:
==================================================
    user: the human
    customer: an instance of a user who has placed an order
        placing an order means adding a row in orders
    loosely, user = customer
        a customer is a user who places an order from some location
        it is possible to see many locations from the same user
    order = basket of items
        contains items (products)
        products are from sellers
        sellers are from some location
    realised sale (accounting):
        order status:
            approved
            delivered
            invoiced
            processing
            shipped
        price not null
    unrealised sale (marketing):
        order_status: any
        price: any
    active user:
        any user activity
            any order placed = a row in orders
            a review made at some time

==================================================
kpi definitions:
==================================================

Gross Merchandise Value/Volume (GMV):
    GMV = (sales price of goods) * (number of goods sold)

Average Order Value (AOV):
    AOV = (total revenue) / (total number of orders)
        = GMV / (total number of orders)
    
Churn = (customers lost during period) / (customers at start of perdiod)
    
Customer Lifetime Value (CLV, LTV)
    CLV = [(avg revenue per user) * (gross margin)] / (churn)

MVRV (Market Value to Realised Value)
    = MV / RV

MVRV Z-Score
    = (MV - RV) / stddev(MV)
